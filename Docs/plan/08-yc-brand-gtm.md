# Session 08 — YC application + brand/GTM (non-code; can run parallel to 03–07)

**Goal:** package Conductor for a YC application: narrative, demo, traction plan. Recall
`conductor-brand` — the pitch must sound like the product: quiet, precise, trustworthy. No hype
adjectives; let the demo be the loud part.

## The narrative (draft, refine with user)
- **One-liner:** "Conductor is the Linear of ERP — fast, calm, Arabic-first business software for
  the ~3.8M SMBs in Egypt and MENA that today run on Excel, WhatsApp, and paper."
- **Why now:** (1) Egypt mandated e-invoicing (ETA) — every SMB is forced to digitize; (2) legacy
  local ERPs are Windows-95-grade, global ERPs are English-first and priced for enterprises;
  (3) AI finally makes data entry — the #1 reason SMBs abandon ERPs — disappear (photo → posted
  invoice, Session 02).
- **Wedge:** ETA compliance + AI invoice capture gets us in; the calm, fast, complete ERP keeps us;
  per-company SaaS pricing scales us.
- **Moats:** native-Arabic craft (not translation — a lexicon, RTL-first), Egyptian payroll/tax
  correctness (Session 04), and speed as a brand.
- **Founder story:** built solo end-to-end (5 modules, accounting depth, VAT, e-invoicing, RBAC,
  its own design system + gate suite that mechanically enforces the brand). That velocity IS the
  YC pitch.

## Tasks
1. **YC answers draft** (`Docs/YC/application.md`): every question answered in the brand voice —
   short declaratives, concrete numbers, zero filler. Include the honest state: what's live, what's
   planned (this plan), what traction exists at submission time.
2. **Demo script + video plan** (`Docs/YC/demo.md`): the 2-minute arc — cold signup → provisioned
   company (<60s, Session 06) → photo of a real supplier invoice → AI-drafted bill → confirm →
   ETA-ready e-invoice → owner dashboard showing the numbers move. Every second scripted; the speed
   is the message. Arabic UI on screen, English captions.
3. **Traction plan pre-YC** (`Docs/YC/traction.md`): target 10–20 design partners (Egyptian SMBs —
   trading/distribution first, they feel inventory+VAT pain hardest); free until SaaS billing ships;
   the metric to report: weekly active companies + invoices processed + time-to-first-invoice.
   Channels: accountants (they choose SMB software in Egypt — make accountants heroes with Session
   05's drill-down statements), ETA-compliance urgency, founder-led onboarding.
4. **Marketing site copy** (`Docs/YC/site-copy.md`): one page, both languages, brand triad rules
   apply (Visual Identity System owns off-app surfaces). Screenshot-first, adjective-light.
5. **Competitive one-pager:** vs Odoo (heavy, poor Arabic), local desktop ERPs (no cloud, no AI),
   Excel (no trust). One honest table.
6. **Numbers hygiene:** market size sourced (CAPMAS SMB counts, e-invoicing mandate stats) — verify
   current figures at write time (WebSearch), don't trust memory.

## Done bar
- Four docs drafted in `Docs/YC/` for user review — user edits voice/facts, nothing submitted
  without their sign-off.
- Demo script executable against the actual product (every step works or is flagged as
  pending-session-N).
